# Minti Motorsport — website

Marketing site for Minti Motorsport: a UK-registered, family-run rally team operating from
Nairobi. One commercial job — convert serious enthusiasts into **qualified enquiries for a
seat on an East African rally**.

Design rationale: `DESIGN-PLAN.md`. Judgement calls: `DECISIONS.md`.
Outstanding facts: `CONTENT-TODO.md`. Photography: `ASSETS-NEEDED.md`.
Pre-launch sign-off: `CLIENT_CONFIRMATION_CHECKLIST.md`.

## Stack

- **Next.js 15** (App Router, TypeScript strict), Tailwind CSS v4 (token layer in
  `app/globals.css` — no arbitrary hex in components)
- **GSAP + ScrollTrigger** (pinned home sequence, dynamically imported, desktop-only),
  **Lenis** smooth scroll (fine pointers only), CSS/IntersectionObserver reveals
- **React Hook Form + Zod** with a server action for the enquiry flow
- **MDX journal** via `gray-matter` + `next-mdx-remote` from `content/journal/`
- Fonts self-hosted via `next/font/local` (`app/fonts/`)

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

## Where content lives

Everything editable is under `content/` — components never hard-code copy or facts:

| File | Contents |
|---|---|
| `content/site.ts` | Name, verified facts, nav, CTA vocabulary, contact (env-gated), roadbook stage metadata |
| `content/home.ts`, `drive.ts`, `cars.ts`, `team.ts`, `heritage.ts` | Per-page copy |
| `content/journal/*.mdx` | Journal posts (frontmatter: title, date, category, excerpt, cover) |
| `content/images.generated.ts` | Image manifest — regenerated by `npm run placeholders` |
| `lib/schemas.ts` | Enquiry options and validation (budget bands live here) |

Factual placeholders are `{{TODO: …}}` strings; the `<Todo>` component renders them as
visible dashed "TBC" chips so nothing invented ever looks final. The full list is in
`CONTENT-TODO.md`.

### Swapping in a CMS later

Pages import plain typed objects/functions from `content/` and `lib/journal.ts`. To move to
Sanity/Storyblok: reimplement those modules to fetch instead of read from disk, keep the
exported shapes, and the components don't change. `lib/journal.ts` is the worked example —
`getJournalPosts()` / `getJournalPost(slug)` are the only entry points.

### Replacing placeholder photography

1. Drop the real image over the same path in `public/images/` (target dimensions in
   `ASSETS-NEEDED.md`).
2. Run `npm run placeholders` — existing files are kept as-is; the manifest's dimensions
   and blur data are regenerated from what's actually on disk. (Delete a file to get its
   placeholder back.) Alt text in the manifest doubles as the shot brief.

## Lead delivery (configure before launch)

`lib/leads.ts` is the adapter. Configure any combination in `.env` (see `.env.example`):

- `LEAD_WEBHOOK_URL` — POST JSON anywhere (Zapier/Make/own endpoint)
- `RESEND_API_KEY` + `LEAD_TO_EMAIL` (+ `LEAD_FROM_EMAIL`) — email via Resend
- CRM — fill in the clearly-marked `appendToCrm()` stub in `lib/leads.ts`

With nothing configured, submissions are **logged loudly server-side** and never silently
discarded — but configure a destination before launch. Spam: honeypot field + sub-4s timing
check (flagged server-side, bots receive a normal success).

## Enquiry flow

`/enquire` — five steps, one question per screen, answers persisted to `sessionStorage`.
Email + phone are the only required fields. The optional book-a-call step appears only when
`NEXT_PUBLIC_BOOKING_URL` is set. Analytics events fire per step (see `lib/analytics.ts`).

## Analytics

Adapter in `lib/analytics.ts`; loader in `components/analytics/`:

- `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` — Plausible, cookieless, no banner
- `NEXT_PUBLIC_GA_ID` — GA4, loaded **only after** the consent banner is accepted
- Neither set → `track()` is a no-op, nothing loads

## Accessibility & motion

- `prefers-reduced-motion: reduce` disables every animation (single kill-switch at the
  bottom of `app/globals.css`), Lenis and GSAP never initialise, all content shows final
  state — verified with emulated screenshots.
- Focus rings are sodium and survive dark sections; skip link; semantic landmarks;
  the enquiry flow is fully keyboard operable.

## Deploy

Standard Next.js on Vercel: import the repo, set env vars from `.env.example`, deploy.
Set `NEXT_PUBLIC_SITE_URL` to the production domain — canonical URLs, OG tags and
sitemap all derive from it.
